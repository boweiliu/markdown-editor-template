# First version (2026-11-05)

A markdown viewer and editor whose default is to suggest and comment, saving the suggestions and comments inside the
file as CriticMarkup. Opens any markdown file in the workspace by path, saves as you type without reformatting what
you did not touch, notices when an agent changes the file, and keeps the earlier versions of every file it saves.

## Fix (2026-11-05)

The toolbar no longer leaves a gap under the top bar when it wraps onto two rows in a narrow window: the top bar,
toolbar and notices now stick to the top as one piece.
